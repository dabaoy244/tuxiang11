# 外部域独立基准行：COVERAGE（零样本跨数据集，100 真 + 91 篡改 = 191 张）

- 定义：COVERAGE 是**复制-移动**篡改数据集，与训练域（ForenSynths 生成图 / CASIAv2 拼接·复制移动）**不同源**，且全程**未参与任何训练**。
- 因此本表是**零样本跨数据集**结果，回答「迁移到没见过的伪造类型还行不行」，**不可**与训练域内部 test 指标并列。
- 定位口径：★ 只报 `miou_tampered_only`（在 GT 真有前景的图上逐图平均，与 ManTra-Net / SPAN / CAT-Net 可比）。
- ⚠️ 池化 `miou` / `miou_per_sample` / Dice / PixelAcc 受「COVERAGE 真实图自带全零掩码文件」影响（这些图会被计入定位池、误报被罚），**跨数据集不可比**，故不列。
