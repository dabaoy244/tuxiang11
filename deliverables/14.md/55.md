**结论：现在不要整体重切。现有池子先冻结、先审计；只有为“新结论”建版本化新池时才改。**

理由：一改就会破坏 456/462v2/469 等全部历史数字的可比性。当前问题不是“数据必须重做”，而是“现有数据无法支撑某些声明”。

| 分区 | 现在改吗 | 必须处理的问题 |
|---|---|---|
| **train 240,000** | **不改** | 若要宣称“跨生成范式”，必须另建**范式留出**训练臂（GAN-only / Diffusion-only）；不能只在混合池上加数据就当跨范式 |
| **val_thr 43,227** | **不改原池**；新实验建新池 | 扩散族为 **0** ⇒ 扩散族的 ACC/bAcc 没有冻结阈值来源。凡 val_thr 未覆盖的族，只能报阈值无关的 AUC/AP，或明确标“不可判” |
| **val_sel 35,852** | **不改原池**；新实验建新池 | GAN 为 **0**、假图全为扩散/局部编辑 ⇒ 用它做模型选择会把 GAN 能力排除在选择目标外；新池须按目标族分层覆盖 |
| **test 79,567** | **冻结，不改** | 可继续作多源基准；**不能**用它支持“跨生成范式”——test 假图中 GAN 占 72.4%，扩散仅 CoCoGlide **1,024 张（2.7%）** |

**数据侧必须先做的四件核查（零训练）**

1. 跨 dataset 底图交集：当前门禁按 `(dataset,id)` 比较，跨 dataset 同底图**检不出**。依据：`scripts/g2_build.py:183-184`、`scripts/g3_gates.py:188-207`。
2. 定位池 real:tampered 比例：train real 5.0% vs 评测 88.4%，若属实，定位结论不可外推。
3. 训练池 JPEG QF 分布：用 `PIL.Image.quantization` 反推。
4. manifest 与 registry 的生成器族数是否一致。

**触发重切的唯一条件**：第 1 项查出 train∩test 非空。否则不重切。

补充：**“3,721 张扩散训练样本是否足够”无对应文献/源码支撑，无法给出该判断**。只能作为新预注册里的样本预算写明，不能预判结论。

# 二、申报书要不要写“跨生成范式泛化”？

**结论：不需要把验收口径改成这个词；可以把它写成“研究目标/扩展评估”，但不能写成“已完成能力”。**

依据：
- 原申报书 §（二）1.1、§6.3 用的是“**跨生成模型数据集**”“检测准确率≥91%”，并未承诺范式级泛化。原文 `D:\zcode work\_shenbaoshu.txt`。
- 申报书修订稿也明确要求：跨生成器指标必须写成“**训练阶段未见过的生成器子集 + 阈无关 AUC + 固定阈值协议**”，并报逐生成器分项。依据：`deliverables/03_申报书修订成稿.md` §4.1。
- `deliverables/03` §1.1 明确：**评审期什么都不要改**；立项后到中期前，用《研究内容调整说明》细化口径。

**为什么现在不能写成“跨生成范式泛化”**：
1. 训练池已含扩散（`GenImageDiff` 3,721 张）与 AI 局部编辑（48,000 张）⇒ 不存在“只训 GAN、测扩散”的范式留出。
2. test 扩散仅 1,024 张，val_thr 扩散为 0 ⇒ 无法形成可判定的范式级结论。
3. 文献的跨族结论都靠**明确留出**：P126 VIB-Net 是“训 SDv1.4 测 15 个生成器 / 训 ProGAN 测 17 列”，P018 SPAI 是“只用 1 个 latent diffusion 的假图训练、测 13 个生成器”。依据：P126 §2.3、§3.1；P018 §2.3、§3.1。

**可写与不可写**：

| 场合 | 建议写法 |
|---|---|
| 研究目标 / 背景 | 可写：“面向训练中未见的生成器及生成范式，评估空频特征与信息瓶颈的泛化能力” |
| 6.3 硬指标 | **保持**“未见生成器子集 + AUC/AP 主口径 + ACC/bAcc 副口径”，不要改成范式级 |
| 中期/结题成果 | 只有完成 GAN→Diffusion 与 Diffusion→GAN 两个留出实验后，才可写“跨生成范式”；否则只写“多生成器/多篡改类型” |
| 现在已有结果 | 只能写“在 cls_v2 多源池上的多生成器检测与定位” |

# 三、输入端要不要改？

**结论：主线输入端不改，维持现状；只保留已修的口径一致性。**

| 项 | 决定 | 依据 |
|---|---|---|
| 几何 | **保持 224 / crop** | 456 四臂几何判决均不可判（A−B +0.158、D−C +0.626）；改默认只会破坏可比性 |
| 预处理 | **保持“训练套什么、评测套什么”**，空串时逐位不变 | `scripts/ab_eval_family.py` 的 `--preproc` 与 `test_eval_preproc_parity.py` |
| 阈值 | **保持 `--thr-from` 冻结**，缺族直接拒收 | `scripts/p0_verdict.py`；D-028 |
| 确定性 | 保持 `--deterministic` | 456/469 全部主表口径 |

**不改的理由（论文侧）**：
- 几何增益方向不统一：P013 的 SAFE Resize→Crop 为 **R.Acc +33.5pp / F.Acc −3.5pp**——总 Acc 涨、假图侧反而降；只报宏 AUC 会把这件事平均掉。依据：P013 §2.2、§3.1。
- 输入端改动不能替代数据协议：P018 的结论来自“原生分辨率切块 + 注意力聚合”，不是把 224 换一种裁剪；P022 的像素折返也是独立预处理范式。依据：P018 §2.2；P022 §2.2。

**未来若做输入臂，必须满足**：单变量；同时报 R.Acc/F.Acc；逐族报；阈值不重搜；否则不立项。E/F/G 三算子当前“无可检出收益 + bAcc 显著下降”，不采纳。

# 四、你的下一步理解：**基本正确，需加两个前置条件**

原表述：停止加预算 → 修正叙事与评测口径 → 完成数据核查 → 新预注册测 β、融合结构、定位侧。

**修正版**：

1. **停止的是“当前配方单纯加预算”和 P1–P4**，不是停止所有训练。依据：`deliverables/469` §9.5。
2. **修正叙事与评测口径 + 数据核查要并行**，并在新训练前完成；其中 **val_thr/val_sel 的族覆盖**必须先定，否则新臂的 ACC/bAcc 仍不可判。
3. **新预注册（475）第一条不是 β，而是“配方 + 选点规则”**：
   - 逐轮计算族等权宏 AUC，按宏 AUC 选 best，不再用 `val_cls_auc`；
   - 学习率/增强/正则为单变量臂；
   - 否则 β 在已饱和配方上测，仍然不可解释。依据：`deliverables/469` §9.5。
4. **β 与结构分臂**：β 修法三选一；融合结构另设 cross/cmf + pin `attn_kv` 臂；不要一条臂同时改三件事。依据：`deliverables/473f` C-06、C-09；P162 §2（K/V 分置）。
5. **定位 A-1 放在数据核查之后**：门槛用 **1.512pp** 而非 3.187pp；三探针 + 面积分层 + 频域辅助头独立掩膜监督。依据：`scripts/_thresholds.json:30-36`、`scripts/eval_tiled_loc.py:148-152`；P027 §3/§6（频域单支 F1 0.130 vs RGB 0.330）；P036 §3.2（无监督 DCT 跨域 0.507→0.457，加监督 0.492 仍低于 0.507）。

**一句话**：你的路线对；只需把“改配方与选点规则”提到 β 之前，把“验证集族覆盖”提到新预注册之前。
