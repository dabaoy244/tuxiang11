# 01 · 环境搭建

## 一、软硬件建议

| 项目 | 最低 | 建议 | 说明 |
|---|---|---|---|
| GPU | GTX 1660 6G | **RTX 3090 / 4090 24G** | CLIP-ViT-B/16 + batch 16 大约吃 8~10G 显存 |
| 内存 | 16 GB | 32 GB | DataLoader 多进程 + ForenSynths 10 万张的索引 |
| 磁盘 | 100 GB | 500 GB SSD | 三套数据集原始 + 规范化后，约 200~300 GB |
| CPU | 4 核 | 8 核以上（Intel 带 AVX-512/VNNI 更好） | 端侧部署测试要测 Intel CPU |
| 系统 | Windows 10 / Ubuntu 20.04 | Ubuntu 训练 + Windows 部署 | 训练端 Linux 更省心 |

**没有 GPU 怎么办：**
- 训练：用学校集群 / 实验室服务器 / 云 GPU（AutoDL、恒源云，3090 约 1~2 元/小时）。
  按本项目 70 轮 × 数天的量，云上大约 200~500 元，**申报书的"租借服务器"预算 4000 元足够**。
- 只是想把代码跑通：CPU 也能跑（用 `--demo` + `backbone: tiny_vit`），几分钟出结果。

## 三、依赖版本注意事项（踩过的坑）

| 包 | 版本要求 | 坑 |
|---|---|---|
| `torch` | ≥2.1 | 2.14 起 `nn.TransformerEncoder` 的融合算子**无法导出 opset 17**；本仓库的兜底骨干已改为手写注意力块规避 |
| `transformers` | ≥4.35 | 加载 CLIP 用 `CLIPVisionModel`；新版本（5.x）API 名称有变，若报错请固定 `transformers==4.40.*` |
| `openvino` | ≥2024.1 | **2024.x 的 wheel 只支持到 Python 3.12**。用 Python 3.13 请装 `openvino>=2025.0`（API 兼容） |
| `onnx` | ≥1.14 | 与 `onnxruntime` 版本要匹配，否则加载模型会报 ir_version 不兼容 |
| `opencv-python` | ≥4.8 | 服务器无 GUI 用 `opencv-python-headless`；`cv2.imread` **不支持中文路径**，本仓库统一用 `imdecode + np.fromfile` 兜底 |
| `PyQt5` | 5.15.x | 需要 `PyQt5-Qt5` + `PyQt5-sip` 三个包齐全，缺任一个会 `ModuleNotFoundError: PyQt5.QtWidgets` |

**关于 `pycocotools` / `scipy`：** 本仓库的指标计算全部手写实现（`src/engine/metrics.py`），
**不依赖 scipy / sklearn**，减少环境冲突。需要 ROC 曲线绘图时再单独装 matplotlib。

## 四、CLIP 预训练权重

`transformers` 默认**不会**自动联网下载。三种处理方式：

### 方式 1：联网下载（有外网时最简单）

```bash
# Windows
set VIB_NET_ALLOW_DOWNLOAD=1
# Linux
export VIB_NET_ALLOW_DOWNLOAD=1

python -c "
from transformers import CLIPVisionModel
CLIPVisionModel.from_pretrained('openai/clip-vit-base-patch16')
"
```

国外源慢的话用镜像：

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

### 方式 2：预先下载放本地（推荐，实验室机器常常不通外网）

把权重放到 `pretrained/clip-vit-base-patch16/`，目录里至少要有：
```
pretrained/clip-vit-base-patch16/
├── config.json
├── preprocessor_config.json
└── model.safetensors        # 或 pytorch_model.bin
```
配置里 `model.spatial.clip_local_dir` 已指向该路径，脚本会**优先从本地加载**。

> 下载脚本（在能联网的机器上执行，再把目录拷过来）：
> ```bash
> huggingface-cli download openai/clip-vit-base-patch16 \
>   --local-dir pretrained/clip-vit-base-patch16 \
>   --local-dir-use-symlinks False
> ```

### 方式 3：不加载 CLIP，先跑通流程

```yaml
model:
  spatial:
    backbone: "tiny_vit"     # 结构同构的轻量随机初始化骨干
```
⚠ **此模式下所有指标都没有意义**，只用于验证代码链路是否正确。
论文/结题必须切回 `clip_vit_b16`。

## 六、常见报错速查

| 报错 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError: PyQt5.QtWidgets` | PyQt5 只装了壳 | `pip install PyQt5 PyQt5-Qt5 PyQt5-sip` |
| `UnsupportedOperatorError: aten::_transformer_encoder_layer_fwd` | 用了 `nn.TransformerEncoder` 导出 ONNX | 本仓库已改手写注意力块；自己加模块时避免融合算子 |
| `The value for parameter "input_model" must be existing file` | ONNX 没导出成功就去转了 | 先跑 `src/deploy/export_onnx.py`，确认 `deploy/*.onnx` 存在 |
| `OSError` 加载 `openai/clip-vit-base-patch16` | 无网络 / 需要登录 | 用方式 2 本地权重，或 `backbone: tiny_vit` 先跑通 |
| `CUDA out of memory` | batch 太大 | 降 `train.batch_size`，或开 `train.amp: true`（bf16） |
| `RuntimeError: DataLoader worker ... killed` | 多进程 + 内存不足 | 把 `data.num_workers` 设为 0 或 2 |
| 中文路径图片读不出来 | `cv2.imread` 不支持中文 | 用 `cv2.imdecode(np.fromfile(path, np.uint8), ...)`（本仓库已内置） |
| Windows 上 `--workers 4` 卡住 | 缺少 `if __name__ == '__main__'` 保护 | 本仓库脚本都有保护；自己写脚本要注意 |

## 七、Git 与团队协作建议

`.gitignore` 应包含：

```
data/
checkpoints/
outputs/
deploy/*.onnx
deploy/*_ir*/
*.pt
*.pth
__pycache__/
.venv/
```

**约定：**
- 每次改配置跑实验就提交一次；
- commit message 格式：`exp: <阶段> <关键改动> -> <主要指标>`，
  例如 `exp: stage3 beta0.3 -> val_acc 0.912`；
- 这样半年后还能从 git log 复现任意一次实验，写论文时不用"考古"。
