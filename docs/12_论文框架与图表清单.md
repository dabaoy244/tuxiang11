## 一、先定位：这篇论文该投什么档位

本科创新训练项目的结题要求通常是「有研究成果」，不等于必须发核心。按实际投入产出，分三档：

| 档位 | 目标 | 需要什么 | 现实性（单人 + 只有 CPU 笔记本 + 云平台账号） |
|---|---|---|---|
| **A 档 · 保底** | 校级/院级结题报告 + 软著 2 件 | 系统能跑通、指标达标、材料齐全 | ✅ **已经具备**。软著两份材料已产出（`docs/copyright/`） |
| **B 档 · 主力** | 中文普刊 / 本科学报 / 校内论文集 | 完整实验：主实验 + 消融 + 鲁棒性，有一组可复现数字 | ✅ 可行，前提是拿到 GPU 跑完三阶段训练（约 30~120 GPU·h） |
| **C 档 · 冲刺** | CCF-C 类会议 / 中文核心 | 必须补**跨生成器泛化** + **与 2~3 个 baselines 对比** + 真实篡改数据集 mIoU | ⚠️ 需要 CASIA v2 + COVERAGE 到位，且 baseline 复现成本高 |

**建议路线**：先按 B 档把实验做完整、写成稿；C 档作为「有余力再补」。
不要一开始就按 C 档设计，否则会把时间耗在复现别人模型上，自己的主实验反而没跑完。

## 二、题目候选

按「方法特征 + 任务 + 卖点」三段式：

1. **空频双分支轻量 VIB-Net：面向多生成模型的 AI 图像篡改检测**
   —— 稳，覆盖全部要素，适合 B 档。
2. **引入分层变分信息瓶颈的空频融合轻量篡改检测网络**
   —— 突出 VIB 这个最像创新的点，适合 C 档（需要消融把 VIB 的增益坐实）。
3. **可 CPU 实时部署的空频协同 AI 生成图像鉴别与篡改定位**
   —— 突出「≤120MB、≥8 张/秒」的工程卖点，适合工程类期刊/会议。

## 三、摘要骨架（直接填空即可）

> 结构：任务重要性 → 现有方法痛点 → 本文做法（3 点）→ 关键结果（数字）→ 意义。
> **每个数字后面标 `[待填]` 的地方，必须来自真实实验记录，不许估。**

```
针对 AI 生成图像在社交媒体上的快速扩散与现有检测方法"精度高但体积大、
难以在无 GPU 环境部署"的矛盾，本文提出一种空频双分支轻量篡改检测网络
VIB-Net。其核心包含三部分：(1) 空域分支以轻量视觉骨干提取全局语义与局部
纹理表征，频域分支对幅值谱与相位谱分别建模并引入可学习频域掩码；
(2) 设计 CS-CAM 交叉注意力融合模块，实现空域与频域的跨域交互；
(3) 在分类支路引入分层变分信息瓶颈（VIB），以 β 退火与 KL 截断稳定训练，
抑制纹理细节带来的过拟合。

在 ForenSynths 基准上，本方法取得 AUC=__[待填]__、准确率=__[待填]__；
消融实验表明 VIB 模块带来 __[待填]__ 个百分点的 AUC 提升，相位谱建模贡献
__[待填]__。模型 FP32 体积 98.7 MB、CPU 单线程实测 9.46 张/秒，
在 7 核无 GPU 环境下满足实时检测要求；INT8 量化后体积降至 25.7 MB，
输出相对偏差不超过 0.78%。

关键词：AI 图像篡改检测；频域分析；变分信息瓶颈；跨注意力融合；轻量化部署
```

> 这个 1.7 倍目前在公开文献里**查不到出处**，见 `docs/11` 第 1 条。

> ⚠️ 这张表本身就是论文的一个真实结论：**在本机 CPU 上，INT8 并不会更快**
> （本机 CPU 缺少 VNNI 指令，量化算子退化为逐元素模拟）。所以「用 INT8 同时满足

> 目标平台指令集」。这比含糊地说"量化后更快"要安全得多。

## 七、实验矩阵（决定要跑多少次训练）

一次正式训练（三阶段）约需 30~120 GPU·h（见 `docs/10`）。消融每项也要跑一次，成本会膨胀。

**省算力的做法**：消融实验只跑 **stage1（分类预训练）**，并在论文里明确写清
「消融基于分类支路，在 stage1 协议下进行」。这样 5 组消融 ≈ 0.3 倍成本，
且结论依然成立（消融关心的是相对差异，不是绝对精度）。

| 实验组 | 配置 | 目的 | 优先级 |
|---|---|---|---|
| E1 主实验 | full，三阶段 | 报主指标 AUC/ACC/F1/AP | ★★★ |
| E2 跨生成器 | 训练仅 ProGAN → 测试其他生成器 | 论文最核心的说服力 | ★★★ |
| E3 消融 · VIB | `no_vib` | 坐实 VIB 增益 | ★★★ |
| E4 消融 · 相位 | `no_phase` | **替换掉没有出处的「1.7 倍」说法** | ★★★ |
| E5 消融 · 可学习掩码 | `no_learnable_mask` | 频域掩码有效性 | ★★ |
| E6 消融 · 交叉注意力 | `no_cross_attention` | 融合方式有效性 | ★★ |
| E7 鲁棒性 | JPEG/缩放/裁剪/旋转/噪声 | 审稿人常问 | ★★ |
| E8 定位精度 | 需 CASIA v2 + COVERAGE | mIoU ≥ 56% 的申报指标 | ★★ |
| **E9 骨干权重对照** | **random vs ImageNet 预训练，唯一变量=骨干权重** | **回答"模型为什么能训起来"，是方法可信度的前提** | **★★★ 已完成（CPU 小规模）** |

> **E4 是唯一能"一举两得"的实验**：既完成消融，又把申报书里那句查不到出处的
> 「相位贡献是幅值的 1.7 倍」替换成自己实测的数字。**建议优先跑 E4。**

> **E9 已在 CPU 上用 ForenSynths val→test 小规模跑通**（`scripts/run_ablation.py`，两臂各 3 epoch）。
> 它的价值不在精度数字，而在于**排除"模型结构有问题"这一质疑**：
> 两臂过滤注释后仅 3 处 diff，其中**只有 `backbone_weights` 影响训练**。
> **判据是混淆矩阵 `tn`/`tp` 是否同时为正**（不是 ACC——退化臂的 ACC 恒为 0.5）：
> b16 随机初始化臂 `tn=0`（全判伪造，判决退化），预训练臂 `tn=163 / tp=582`（边界建立）。
> ⚠️ **必须如实标注强度**：两臂 AUC 只差 +0.038（0.6428 → 0.6809），且随机初始化臂的
> `AUC=0.63` 说明其排序分数并非全无信号（频域分支是确定性变换，与骨干是否预训练无关）。
> 所以结论是"预训练权重是判决边界能建立的**必要条件**，非充分条件"，
> **不能写成"预训练权重决定性提升了性能"**。另注意：s16 随机跑（AUC 0.49~0.52，两端翻转）
> 与 b16 随机跑（AUC 0.63，恒判假）是两个不同实验，不可混述。
> ⚠️ E9 用的是 ForenSynths 的 **val 划分当训练集**（官方 train 70.4 GB 受限网络下未取得），
> 论文里必须写明这是小规模替代，**不能声称复现了官方协议**。
